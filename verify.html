Independent Verification

Verify any ZTR receipt without an account. Two methods, same result.

Option 1 — Verify by Receipt ID

Enter the Receipt ID from the PDF receipt or QR code (e.g. ZTR-20260801-...)

Option 2 — Verify by Document Hash

Paste the SHA-256 hash of your document's text content to check if it matches any receipt.

How independent verification works

Level 1 — Receipt lookup. Enter the Receipt ID above. If found, the receipt exists in the ZTR registry and has not been fabricated.

Level 2 — Hash match. Copy the text of the original document into any SHA-256 calculator. If the hash matches the one on the receipt, the document has not been modified since verification. This step does not require trusting ZTR.

Level 3 — Qualified timestamp. The timestamp on each VERIFIED receipt was issued by Aruba PEC S.p.A., a Qualified Trust Service Provider under EU Regulation 910/2014 (eIDAS). The timestamp token can be verified independently using any RFC 3161 validation tool. This does not require trusting ZTR or the professional — the date is guaranteed by a qualified third party recognised across 27 EU countries.
